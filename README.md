# oracle_one_grupo_9_-_desafio
Aplicação que permite inserir nomes, um a um, criando uma lista. Em seguida, permite realizar um sorteio aleatório; os nomes adicionados por meio do campo de texto + botão "Adicionar", serão exibidos um a um, em uma lista na página; ao terminar a inclusão dos nomes, pode usar o botão "Sortear Amigo", para exibir o nome do sorteado na tela.
